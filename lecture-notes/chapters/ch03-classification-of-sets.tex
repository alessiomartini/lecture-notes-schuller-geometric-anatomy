\section{Classifying spaces by structure-preserving maps}\label{sec:cl-idea}

With the axioms of set theory in place we can proceed to an important topic, the classification of sets
\ts{3}{1}{0:04}. Every time a notion is defined in mathematics one immediately asks for its classification: how many
different objects of this type are there, and how does one get an overview of the structure \ts{3}{1}{0:26}? It is fine
to write down a definition, and fine to write down nine axioms, but we would like an overview of what types of sets
there are \ts{3}{1}{0:47}. This is not special to set theory; it is a recurrent theme in mathematics.

\begin{intuition}[The recurrent theme of mathematics]\label{int:cl-theme}
Study, more precisely: the \textbf{classification of spaces by means of structure-preserving maps between those
spaces} \ts{3}{1}{1:16}\ts{3}{1}{1:37}.
\end{intuition}

Two words need clarifying, \emph{space} and \emph{map} \ts{3}{1}{1:58}. A \textbf{space} is usually meant to be a set
\emph{equipped with some structure} \ts{3}{1}{2:21}. At the beginning of the course Schuller announced that layers of
structure would be put on top of each other, equipping sets with more and more structure: topology is the next step,
then a differentiable structure, and so on \ts{3}{1}{2:41}. But it could also be a group structure, say, an operation on
a set \ts{3}{1}{3:02}. Whenever such a structure is given, the principle applies.

The case of plain sets is a trivial instance: a set without additional structure is still a set, and a
structure-preserving map between sets is simply a map, because there is no structure that could be preserved (apart
from the structure of the set itself, which is the lowest-level structure) \ts{3}{1}{3:22}\ts{3}{1}{3:43}. So we first need
a notion of map.

\section{Maps}\label{sec:cl-maps}

\begin{definition}[New concepts: map]\label{def:cl-map}
A \textbf{map} $\varphi\colon A\to B$ from a set $A$ to a set $B$ is a relation $\varphi$ such that
\[
  \forall a\in A\ \ \exists!\, b\in B\colon\ \varphi(a,b)
\]
\ts{3}{1}{4:07}\ts{3}{1}{4:29}. Here $\varphi(a,b)$ means that the relation $\varphi$ is true on the pair $(a,b)$, as in
\cref{def:se-relation} (a relation of two variables is true or false); if $A$ and $B$ are sets, a map is such a special
relation \ts{3}{1}{4:49}.
\end{definition}
The word \emph{map} is used as a synonym of \emph{function}.

The standard notation hides that $\varphi$ is a relation eating two variables and producing a truth value
\ts{3}{1}{5:10}. One writes
\[
  \varphi\colon A\to B,\qquad a\mapsto\varphi(a),
\]
assigning to each $a\in A$ a value $\varphi(a)\in B$ \ts{3}{1}{5:32}. If $\varphi$ is a relation this is an abuse of
notation, since a relation needs two objects to produce a truth value; but since for every $a\in A$ there is exactly one
$b\in B$ with $\varphi(a,b)$, $\varphi(a)$ is \emph{defined} to be precisely that unique $b$ \ts{3}{1}{5:52}.

That is the standard notation \ts{3}{1}{6:13}. Structurally, though, it is correct to keep in mind that a map is a
relation. If one does not look at a map as a relation, one gets into trouble: ``to every $a$ there is assigned a unique
$b$'', but what does it mean to \emph{assign} to one element another element? The notion of assigning is not defined;
it comes from a relation \ts{3}{1}{6:13}\ts{3}{1}{6:33}\ts{3}{1}{6:53}.

\begin{definition}[New concepts: domain, target, image]\label{def:cl-image}
Let $\varphi\colon A\to B$ be a map \ts{3}{1}{6:53}.
\begin{itemize}
  \item $A$ is the \textbf{domain} and $B$ the \textbf{target} (also called codomain) of the map \ts{3}{1}{7:13};
  \item the \textbf{image} of $A$ under $\varphi$ is
        \[
          \operatorname{im}_\varphi(A):=\varphi(A):=\{\varphi(a)\mid a\in A\}\subseteq B,
        \]
        the set defined by restricted comprehension (\cref{thm:se-comprehension}) inside $B$, since by definition all values
        $\varphi(a)$ lie in $B$ \ts{3}{1}{7:13}\ts{3}{1}{7:35}\ts{3}{1}{7:55}.
\end{itemize}
\end{definition}
The name \emph{image} is the optical one: the set of ``pictures'' of the points of $A$ in $B$; \emph{target} is what
the arrow aims at.

Further well-known notions follow \ts{3}{1}{7:55}.

\begin{definition}[New concepts: surjective, injective, bijective]\label{def:cl-bij}
A map $\varphi\colon A\to B$ is
\begin{itemize}
  \item \textbf{surjective} if its image coincides with the target, $\varphi(A)=B$: every point of the target is hit by
        the map \ts{3}{1}{8:20};
  \item \textbf{injective} if equal values have equal arguments: $\varphi(a_1)=\varphi(a_2)\Rightarrow a_1=a_2$
        \ts{3}{1}{8:20}\ts{3}{1}{8:40};
  \item \textbf{bijective} if it is injective and surjective \ts{3}{1}{8:40}.
\end{itemize}
\end{definition}
(The prefix \emph{bi-} means ``both'': a bijection is injective and surjective; \emph{surjective} comes from French
\emph{sur} ``onto'', \emph{injective} from ``to throw in''.) Bijective is by far the most important of the three \ts{3}{1}{9:06}.

\section{Isomorphism of sets and the classification}\label{sec:cl-iso}

\begin{definition}[New concepts: set-theoretic isomorphism]\label{def:cl-iso}
Two sets $A$ and $B$ are called \textbf{(set-theoretically) isomorphic}, written
\[
  A\cong_{\mathrm{set}}B,
\]
if there exists a bijection $\varphi\colon A\to B$ \ts{3}{1}{9:06}\ts{3}{1}{9:28}\ts{3}{1}{9:49}. The qualifier ``set'' (as a
subscript) says that this is the notion of isomorphism in set theory; it is a \emph{key definition}
\ts{3}{1}{9:06}.
\end{definition}
The name comes from the Greek \emph{isos} ``equal'' and \emph{morphe} ``form, shape'': same shape.

Note that we only require the \emph{existence} of some bijection, not a particular one \ts{3}{1}{10:10}. This makes
isomorphy a property of the two sets, which are such that there is such a bijection \ts{3}{1}{10:31}. An important remark
\ts{3}{1}{10:31}: if there is any bijection at all from $A$ to $B$, then generically, that is, except in exceptional
cases, there are many; there is not a unique such bijection. The whole criterion is that one exists \ts{3}{1}{10:51}.

\begin{intuition}[Two classrooms]\label{int:cl-classrooms}
Pair up the elements of $A$ and $B$ \ts{3}{1}{11:12}. If you have two classrooms, one with boys and one with girls, you
can ask whether they are isomorphic: pair up boys with girls, and if nobody is left over there is a bijection. To
every boy you find a girl, and exactly one, so the pairing is injective; and every girl gets a boy, so it is surjective
\ts{3}{1}{11:32}\ts{3}{1}{11:53}. This is the intuition of ``equal size'', but better than an intuitive notion: it is
designed to work also for \emph{infinite} sets. For finite sets equal size is easy, you just count and compare the
numbers; for infinite sets that is not so easy \ts{3}{1}{11:53}\ts{3}{1}{12:14}.
\end{intuition}

Counting is a different thing from classification. This is already the promise of the theme of \cref{int:cl-theme}: the
classification of sets by way of studying structure-preserving maps, which in the case of sets are the bijections
\ts{3}{1}{12:14}\ts{3}{1}{12:35}. We can even clarify what an infinite set is.

\begin{definition}[New concepts: proper subset, infinite, countably infinite, finite]\label{def:cl-infinite}
A \textbf{proper subset} $B$ of $A$ is a subset that is by force not equal to $A$: $A$ contains an element that $B$ does
not contain \ts{3}{1}{12:56}\ts{3}{1}{13:17}. Then
\begin{itemize}
  \item a set $A$ is \textbf{infinite} if there exists a proper subset $B\subsetneq A$ that is set-theoretically
        isomorphic to $A$, $B\cong_{\mathrm{set}}A$ \ts{3}{1}{12:56}\ts{3}{1}{13:39};
  \item an infinite set $A$ is \textbf{countably infinite} if $A\cong_{\mathrm{set}}\N$, the non-negative integers
        \ts{3}{1}{15:02}\ts{3}{1}{15:23};
  \item an infinite set that is not countably infinite is \textbf{uncountably infinite} \ts{3}{1}{15:45};
  \item a set is \textbf{finite} if it is not infinite (now ``otherwise'' refers to this level of the structure)
        \ts{3}{1}{16:09}.
\end{itemize}
\end{definition}
For \emph{finite} sets the existence of such a proper subset is an immediate contradiction: if $A=\{1,2,3\}$ and
$B=\{1,2\}$, there is no bijection between them \ts{3}{1}{13:39}\ts{3}{1}{14:00}. For infinite sets this impossibility is
precisely the signature of the infinite: a proper subset that is nevertheless isomorphic to the whole. A typical
example are the integers $\mathbb Z$ and the non-negative integers $\N$: $\N$ is a proper subset of $\mathbb Z$ (it
suffices that $-1\notin\N$), but nevertheless $\mathbb Z\cong_{\mathrm{set}}\N$, because one can write down a
bijection \ts{3}{1}{14:00}\ts{3}{1}{14:20}\ts{3}{1}{14:41}.

\begin{exercise}[A bijection between $\mathbb Z$ and $\N$]\label{ex:cl-ZN}
Write down a bijection $\mathbb Z\to\N$ \ts{3}{1}{14:41}. (Hint: send the non-negative integers to the even numbers and
the negative ones to the odd numbers.) Hence $\mathbb Z$ is countably infinite.
\end{exercise}

The intuition for countably infinite is that one can \emph{label} the elements: attach a label ``number one'',
``number two'', ``number three'' to all the elements \ts{3}{1}{15:23}\ts{3}{1}{15:45}.

\begin{coursenote}[Not said in class: a caveat on this definition of infinite]
This definition of infinite is due to Dedekind (``Dedekind-infinite''). That it agrees with ``not in bijection with
$\{1,\dots,n\}$ for any $n$'' (the picture used below) needs a weak form of the axiom of choice; for the course the
definition above is the one that is used.
\end{coursenote}

\begin{history}[Bijections and the size of infinite sets]
Not mentioned in class. Comparing sets by pairing them up, and so measuring the size of infinite sets, is due to G.~Cantor.
\emph{Checked.} Cantor, ``Ein Beitrag zur Mannigfaltigkeitslehre'', \emph{J.\ reine angew.\ Math.}\ 84 (1878),
introduced the notion of sets having the same ``power'' by a one-to-one correspondence; the definition of an infinite
set as one equivalent to a proper part of itself is R.~Dedekind, \emph{Was sind und was sollen die Zahlen?} (1888).
\end{history}

\paragraph{Finite sets and their size.} If $A$ is a finite set, then $A$ is set-theoretically isomorphic to
$\{1,2,\dots,n\}$ for some $n\in\N$, and one writes that the size of $A$ is $n$: there are $n$ elements in $A$
\ts{3}{1}{16:29}\ts{3}{1}{16:51}. That is the classification of sets: there is not more to be said. Any questions so far? None
\ts{3}{1}{17:24}.

\section{Composition, inverse and pre-image}\label{sec:cl-comp}

Some more words on maps \ts{3}{1}{17:24}\ts{3}{1}{17:50}. Given two maps one can build a new one.

\begin{definition}[New concepts: composition of maps]\label{def:cl-comp}
Let $\varphi\colon A\to B$ and $\psi\colon B\to C$ be maps (sometimes it is convenient to write the map on top of the
arrow) \ts{3}{1}{17:50}\ts{3}{1}{18:11}. The \textbf{composition} is the map
\[
  \psi\circ\varphi\colon A\to C,\qquad a\mapsto\psi(\varphi(a)),
\]
read ``$\psi$ after $\varphi$'' \ts{3}{1}{18:11}\ts{3}{1}{18:34}.
\end{definition}

Very often this situation is drawn as a diagram \ts{3}{1}{18:56}:
\begin{nfigure}
\begin{tikzpicture}[>=Stealth,node distance=2.4cm]
  \node (A) {$A$};
  \node (B) [right=of A] {$B$};
  \node (C) [below right=1.6cm and 1.2cm of A] {$C$};
  \draw[->] (A) -- node[above] {$\varphi$} (B);
  \draw[->] (B) -- node[above right] {$\psi$} (C);
  \draw[->] (A) -- node[below left] {$\psi\circ\varphi$} (C);
\end{tikzpicture}
\caption{A commutative diagram: going along $\varphi$ and then $\psi$, or directly along $\psi\circ\varphi$, gives the
same result \ts{3}{1}{18:56}.}\label{fig:cl-diagram}
\end{nfigure}
If one is very precise one says that the diagram \textbf{commutes}, which means that one can go this way or that way and,
starting from the same place, arrive at the same result; very often people do not say it, but by drawing the diagram
they do \ts{3}{1}{19:18}. An element of $A$ is first mapped by $\varphi$ and the result is then taken on by $\psi$ and
mapped to $C$; that defines $\psi\circ\varphi$ \ts{3}{1}{19:38}. (The name \emph{commutative diagram} is because the paths
commute, i.e.\ exchange, with the shortcut.)

This might seem overkill as a notation, but we shall later meet situations where many maps go from many places to many
other places, and then diagrams are much more convenient than writing down the data in the traditional way
\ts{3}{1}{19:59}.

Quite obviously, but it needs to be checked (it is a one-liner), composition $\circ$ is an operation on maps (of two maps
it makes a new map), but only if the target of the first map is the domain of the second \ts{3}{1}{20:20}\ts{3}{1}{20:41}.
And $\circ$ is \textbf{associative}: for a third map $\chi\colon C\to D$, $\chi\circ(\psi\circ\varphi)=(\chi\circ\psi)\circ\varphi$,
no matter which is evaluated first \ts{3}{1}{21:04}.

\begin{exercise}[Associativity of composition]\label{ex:cl-assoc}
Check the one-liner: for $a\in A$ both sides send $a$ to $\chi(\psi(\varphi(a)))$, and two maps that agree on every
element are equal \ts{3}{1}{20:20}\ts{3}{1}{21:04}.
\end{exercise}

\paragraph{Identity and inverse.} Composition is needed in order to speak of an inverse map; without it one cannot
\ts{3}{1}{21:27}. The \textbf{identity} on a set $M$ is the map $\mathrm{id}_M\colon M\to M$ in which every element is
assigned to itself; it exists for every set \ts{3}{1}{22:50}\ts{3}{1}{23:11}.

\begin{definition}[New concepts: inverse map]\label{def:cl-inverse}
Let $\varphi\colon A\to B$ be a bijection (only for bijections is the following defined) \ts{3}{1}{21:27}\ts{3}{1}{21:50}.
Then the \textbf{inverse} of $\varphi$ is the map $\varphi^{-1}\colon B\to A$ defined uniquely, so there is no ambiguity,
by
\[
  \varphi^{-1}\circ\varphi=\mathrm{id}_A,\qquad \varphi\circ\varphi^{-1}=\mathrm{id}_B
\]
\ts{3}{1}{21:50}\ts{3}{1}{22:10}\ts{3}{1}{22:30}.
\end{definition}
Drawn as a diagram, $\varphi$ goes from $A$ to $B$ and $\varphi^{-1}$ comes back: going and returning along $A$ must give
the identity on $A$, and the other way round the identity on $B$ \ts{3}{1}{22:30}\ts{3}{1}{22:50}. So the circle $\circ$
is needed to speak of the inverse, and an inverse exists only for bijections \ts{3}{1}{23:11}\ts{3}{1}{23:31}.

\paragraph{Pre-image.} Another notion, which we shall meet in topology in particular, is the pre-image: something like
the image of the inverse, but the map does not need to be a bijection; it can be any map \ts{3}{1}{23:31}.

\begin{definition}[New concepts: pre-image]\label{def:cl-preimage}
Let $\varphi\colon A\to B$ be any map and $V\subseteq B$ a subset of the target. The \textbf{pre-image} of $V$ under
$\varphi$ (with respect to $\varphi$) is the set
\[
  \operatorname{preim}_\varphi(V):=\{a\in A\mid \varphi(a)\in V\}
\]
of all those elements of the domain whose image lies in $V$ \ts{3}{1}{23:52}\ts{3}{1}{24:13}\ts{3}{1}{24:35}.
\end{definition}
The pre-image is always a set \ts{3}{1}{25:16} (restricted comprehension in $A$). If $\varphi$ is a bijection, the
pre-image of a one-element set is always a set with a single element; if $\varphi$ is not a bijection, the pre-image of a
one-element set can be a set with several elements (or empty) \ts{3}{1}{24:55}. These are all basic notions; it is
convenient to fix the notation once and for all \ts{3}{1}{25:16}\ts{3}{1}{25:47}.

\section{Equivalence relations}\label{sec:cl-equiv}

That was the classification of sets \ts{3}{1}{25:47}. Before leaving set theory there is one more topic (of two):
equivalence relations. Schuller goes quickly, assuming that in one form or another they were seen before; the point is to
demonstrate how to get them from the basic axioms, and that everything is fine \ts{3}{1}{25:47}\ts{3}{1}{26:14}.

Equivalence relations provide a heavily used way to look at a set and give it structure, by \emph{identifying} certain
elements, not in any way but in a way that we shall call an equivalence relation \ts{3}{1}{26:14}\ts{3}{1}{26:35}. Much of our
thinking is in equivalence relations \ts{3}{1}{26:35}.

\begin{intuition}[Regrouping]\label{int:cl-regroup}
Somebody coming into this classroom may think of the people in it as one entity (the class) and of Schuller as
another (the teacher of the class); then the thinking might change and he looks at all of us of the same gender, and says
that there are this many men and this many women. Our thinking flips back and forth between regrouping things that are
there, looking at sets in a coarser way \ts{3}{1}{26:56}\ts{3}{1}{27:16}. To group a set entirely, so that really nobody is
left out and there is no intersection between the groups, one employs equivalence relations very cleverly
\ts{3}{1}{27:16}\ts{3}{1}{27:37}.
\end{intuition}

\begin{definition}[New concepts: equivalence relation]\label{def:cl-equiv}
Let $M$ be a set and $\sim$ a relation (a predicate of two variables, written between its arguments, as in
\cref{sec:se-in}: $m\sim n$ means that the relation is true on $(m,n)$) \ts{3}{1}{27:37}\ts{3}{1}{28:04}\ts{3}{1}{28:45}. It
is called an \textbf{equivalence relation} on $M$ if the following three axioms are satisfied \ts{3}{1}{29:47}\ts{3}{1}{30:13}:
\begin{enumerate}
  \item[(i)] \textbf{reflexivity}: $\forall m\in M\colon m\sim m$ \ts{3}{1}{28:04}\ts{3}{1}{28:25};
  \item[(ii)] \textbf{symmetry}: $\forall m,n\in M\colon m\sim n\Leftrightarrow n\sim m$ \ts{3}{1}{28:45}\ts{3}{1}{29:06};
  \item[(iii)] \textbf{transitivity}: $\forall m,n,p\in M\colon (m\sim n\wedge n\sim p)\Rightarrow m\sim p$
        \ts{3}{1}{29:06}\ts{3}{1}{29:27}.
\end{enumerate}
\end{definition}
The names come from Latin: \emph{reflexivus} ``bent back'' (an element is related to itself), \emph{symmetria} Greek
``common measure'' (the relation looks the same from both sides), \emph{transitivus} ``going across'' (the relation
passes through the middle element $n$).

Some examples are in order \ts{3}{1}{30:13}.

\begin{example}[Which of these are equivalence relations?]\label{ex:cl-equiv-ex}
Let $p,q$ be human beings.
\begin{enumerate}
  \item[(a)] $p\sim q:\Leftrightarrow$ ``$p$ is of the same opinion as $q$'' \ts{3}{1}{30:34}. This is reflexive (for
        mentally sound human beings, everyone is of their own opinion), symmetric (if I agree with someone, that person
        agrees with me) and transitive. It is an equivalence relation, ``the basis for democracy'' \ts{3}{1}{30:54}.
  \item[(b)] $p\sim q:\Leftrightarrow$ ``$p$ is the sibling of $q$'' \ts{3}{1}{31:15}. It already fails to be reflexive, since
        you are not your own sibling \ts{3}{1}{31:36}. It would be symmetric. Not an equivalence relation.
  \item[(c)] $p\sim q:\Leftrightarrow$ ``$p$ is taller than $q$'' \ts{3}{1}{32:00}. This is perfectly transitive, but not
        reflexive; one could make it reflexive with ``taller or equally tall'', but certainly it is generically not symmetric
        \ts{3}{1}{32:24}. Not an equivalence relation.
  \item[(d)] $p\sim q:\Leftrightarrow$ ``$p$ is in love with $q$'', Schuller's favourite \ts{3}{1}{32:44}. Not reflexive (on
        occasion there are people who do not like themselves very much), not normally symmetric (``the basis of much drama in
        literature'') \ts{3}{1}{33:05}, and not transitive, ``maybe only in French art cinema'' \ts{3}{1}{33:30}.
\end{enumerate}
So only the first is an equivalence relation. It is very easy to check whether something is one; and if it is, there are
important constructions that one can make, and these have interesting properties: that is why one checks
\ts{3}{1}{33:30}\ts{3}{1}{33:50}.
\end{example}

\begin{definition}[New concepts: equivalence class]\label{def:cl-class}
Let $\sim$ be an equivalence relation on a set $M$. For every $m\in M$ define the set
\[
  [m]:=\{n\in M\mid n\sim m\}
\]
of all those elements of $M$ that are equivalent to $m$ (read: $m$ is equivalent to $n$)
\ts{3}{1}{33:50}\ts{3}{1}{34:36}. It is called the
\textbf{equivalence class} of the element $m$ \ts{3}{1}{34:57}.
\end{definition}
This is a set with a simple definition and a funny name, written with square brackets; it is a subset of $M$, by
restricted comprehension \ts{3}{1}{35:17}\ts{3}{1}{35:38}.

Two key properties of equivalence classes \ts{3}{1}{35:17}\ts{3}{1}{37:02}:

\begin{proposition}[Key properties of equivalence classes]\label{prop:cl-classes}
Let $\sim$ be an equivalence relation on $M$.
\begin{enumerate}
  \item[(i)] If $a\in[m]$, then $[a]=[m]$ \ts{3}{1}{35:17}\ts{3}{1}{35:38}.
  \item[(ii)] For $m,n\in M$ either $[m]=[n]$, or, if they are not the same, $[m]\cap[n]=\emptyset$: the classes have no
        element in common, and there is no other possibility \ts{3}{1}{37:02}\ts{3}{1}{37:23}.
\end{enumerate}
\end{proposition}
The proof is very simple, and you should do it \ts{3}{1}{37:23}\ts{3}{1}{37:52}.

\begin{exercise}[Equivalence classes]\label{ex:cl-classes}
Prove \cref{prop:cl-classes}. (Hint for (i): use symmetry and transitivity to show $[a]\subseteq[m]$ and $[m]\subseteq[a]$,
then \cref{def:se-subset}. For (ii): if $c\in[m]\cap[n]$, apply (i) to $c$ twice.)
\end{exercise}

Property (i) says that, if you start with an element, you build its class; but if you already have the class, you can take
any element out of it and generate the same set from that element. This is interpreted as: any element of an equivalence
class can act as a \textbf{representative} of the class \ts{3}{1}{35:59}\ts{3}{1}{36:20}\ts{3}{1}{36:42}. That is just
terminology.

\begin{intuition}[Same shape]\label{int:cl-shapes}
Assume that you have a set $M$ of elements, for instance carpets $\Box_1,\Box_2,\Box_3$, stars $\star_1,\dots,\star_4$ and
circles $\circ_1,\dots,\circ_4$ \ts{3}{1}{37:52}\ts{3}{1}{38:15}\ts{3}{1}{38:36}. They are really different elements, but
the index does not matter if we consider their shape. Define an equivalence relation: ``have the same shape''
\ts{3}{1}{38:36}. The equivalence classes are: the set of circles, which is the class represented by $\circ_1$ but equally
the class of $\circ_2$ and so on; the set of stars; and the set of squares; those are all \ts{3}{1}{38:57}\ts{3}{1}{39:18}.
Having the same shape is reflexive (everything has the same shape as itself), symmetric, and transitive
\ts{3}{1}{39:18}\ts{3}{1}{39:39}. If we build the classes with respect to an equivalence relation, every element gets
covered \ts{3}{1}{39:39}. Now put on glasses so coarse that they blur: from far away it looks as if the set contained only
three elements, the equivalence classes \ts{3}{1}{39:59}\ts{3}{1}{40:20}.
\end{intuition}

That is no longer the set $M$, which was what was there before; it is the quotient set.

\begin{definition}[New concepts: quotient set]\label{def:cl-quotient}
Let $\sim$ be an equivalence relation on $M$. The \textbf{quotient set} of $M$ modulo $\sim$ is
\[
  M/{\sim}:=\{[m]\in\mathcal P(M)\mid m\in M\},
\]
the set whose elements are the equivalence classes \ts{3}{1}{40:20}\ts{3}{1}{40:41}\ts{3}{1}{41:02}\ts{3}{1}{41:24}.
\end{definition}
The symbol $M/{\sim}$ (read ``$M$ modulo twiddle'') looks dangerous, but it is simple. The name \emph{quotient} is
``how many times does one fit in'': one divides $M$ by the identification. \emph{Modulo} is Latin, ``with respect to the
measure''.

Why can we do this? Where do the $[m]$ lie? This looks like universal comprehension, so we need to convince ourselves
that the set can actually be built \ts{3}{1}{41:24}\ts{3}{1}{41:45}. If written like the definition above it is very likely
restricted comprehension; but then we need the set the equivalence classes come from. The classes are subsets of $M$, so
they are elements of the power set $\mathcal P(M)$; and a power set is a set by the power set axiom
(\cref{ax:se-power}). Everything is fine \ts{3}{1}{41:45}\ts{3}{1}{42:06}. In principle one always has to check that the
object being constructed can actually be constructed \ts{3}{1}{42:06}\ts{3}{1}{42:27}.

\begin{remark}[System of representatives]\label{rem:cl-representatives}
Due to the axiom of choice (\cref{ax:se-choice}) there exists a \textbf{complete system of representatives} for the
equivalence classes of an equivalence relation: a set $R$ together with a bijection between $R$ and the quotient set
\ts{3}{1}{42:27}\ts{3}{1}{42:48}\ts{3}{1}{43:12}\ts{3}{1}{43:36}. One picks from each class one element and puts it into
$R$, so that every single class is represented \ts{3}{1}{43:36}. Which element one picks is not known (``dark''), but the
axiom of choice guarantees that such a system exists, which is of course very useful \ts{3}{1}{43:58}.
\end{remark}
This is one of the two places where choice was announced as needed (\cref{rem:se-choice}).

\section{Maps out of quotient sets: well-definedness}\label{sec:cl-wd}

A further remark: care must be taken when defining maps whose domain is a quotient set, if one uses representatives to
define the map \ts{3}{1}{44:18}\ts{3}{1}{44:38}\ts{3}{1}{45:04}\ts{3}{1}{45:26}. What does this mysterious remark mean?

\begin{example}[Integers modulo two]\label{ex:cl-mod2}
Take $M=\mathbb Z$ and define $m\sim n$ if and only if $m-n$ is an even number, i.e.\ $m-n\in2\mathbb Z$
\ts{3}{1}{45:49}\ts{3}{1}{46:14}. Is it an equivalence relation \ts{3}{1}{46:35}?
\begin{itemize}
  \item reflexive: $m-m=0$ and $0$ is even;
  \item symmetric: if $m-n\in2\mathbb Z$ then $n-m\in2\mathbb Z$, because only the sign changes \ts{3}{1}{46:55};
  \item transitive: also given (the sum of two even numbers is even) \ts{3}{1}{46:55}.
\end{itemize}
So it is. The equivalence class of $0$ is $[0]=\{0,\pm2,\pm4,\dots\}$ and that of $1$ is $[1]=\{\pm1,\pm3,\dots\}$
\ts{3}{1}{46:55}\ts{3}{1}{47:16}\ts{3}{1}{47:37}. The quotient set $\mathbb Z/{\sim}$ consists of just two different elements
(all other classes coincide with one of these two), $\{[0],[1]\}$ \ts{3}{1}{47:37}\ts{3}{1}{48:00}.
\end{example}

Now one could get the idea to inherit the addition from $\mathbb Z$ \ts{3}{1}{48:00}. On $\mathbb Z$ there is the
``kindergarten'' addition, assumed given at this point: a map
\[
  +\colon \mathbb Z\times\mathbb Z\to\mathbb Z.
\]
Here $\mathbb Z\times\mathbb Z$ is the \textbf{Cartesian product}, the set of all ordered pairs of integers
\ts{3}{1}{48:21}\ts{3}{1}{48:42}. What is an ordered pair? That is defined on problem sheet one (problem 5, part b): there the
ordered pairs are defined, and in (b) the Cartesian product, only on the basis of the axioms of set theory; but of course
we have an intuitive notion at this point \ts{3}{1}{48:42}\ts{3}{1}{49:02}\ts{3}{1}{49:23}. (The name \emph{Cartesian}
honours Descartes, who coordinatised the plane.)

We wish to inherit an addition, which deserves a different name, $\oplus$,
\[
  \oplus\colon (\mathbb Z/{\sim})\times(\mathbb Z/{\sim})\to\mathbb Z/{\sim},
\]
taking two elements of the quotient set and returning an element of the quotient set \ts{3}{1}{49:23}\ts{3}{1}{49:46}. The
tentative definition: take an equivalence class, take another class, and define the sum in terms of the addition on
$\mathbb Z$, by taking the representatives that were chosen \ts{3}{1}{49:46}\ts{3}{1}{50:08}\ts{3}{1}{50:29}:
\[
  [a]\oplus[b]:=[a+b].
\]
On the right-hand side, before putting the brackets, one takes the representative $a$ and the other representative $b$ and
uses the addition in $\mathbb Z$ (the plus without the circle); it can only act on the representatives, since those lie in
$\mathbb Z$. After the addition has been completed, only then does one take the equivalence class: that is the
prescription \ts{3}{1}{50:29}\ts{3}{1}{50:49}\ts{3}{1}{51:10}. This is exactly the situation of the remark: a map whose
domain is a quotient set (here even the Cartesian product of the quotient set with itself), defined by using
representatives \ts{3}{1}{51:10}\ts{3}{1}{51:30}.

One says: this is my definition, and that is it. Well, there is an issue, and care needs to be taken, precisely because
the definition could be \emph{inconsistent}; the technical term is that it could be \textbf{ill-defined}, instead of being
\textbf{well defined} \ts{3}{1}{51:30}\ts{3}{1}{51:50}\ts{3}{1}{52:13}. Imagine one takes a different representative $a'$ of
the same class, $[a']=[a]$, and a different $b'$ with $[b']=[b]$. Since the classes are the same, the addition on the
quotient set should yield the same result. But depending on how one uses the representatives, it could nevertheless be that
adding the arbitrarily chosen representatives and then taking the class with respect to the predefined relation leads to a
different result \ts{3}{1}{52:13}\ts{3}{1}{52:35}\ts{3}{1}{52:57}. It is easy to construct such bad examples; this
one is fine, but the independence of the choice of representatives must be checked \ts{3}{1}{52:57}\ts{3}{1}{53:19}\ts{3}{1}{53:44}.

\paragraph{The check.} Let $a',b'$ be such that $a'$ represents the same class as $a$ and $b'$ the same class as $b$; we
hope to prove $[a']\oplus[b']=[a]\oplus[b]$, that is $[a'+b']=[a+b]$ \ts{3}{1}{53:44}\ts{3}{1}{54:05}.
\begin{enumerate}
  \item $[a']=[a]$ means $a'\in[a]$ (by property (i) of \cref{prop:cl-classes}), so the difference $a-a'$ lies in
        $2\mathbb Z$; likewise $b-b'\in2\mathbb Z$ \ts{3}{1}{54:05}\ts{3}{1}{54:26}\ts{3}{1}{54:47}.
  \item Hence there exist $m,n\in\mathbb Z$ with $a-a'=2m$ and $b-b'=2n$ (for the particular $a,a',b,b'$ at hand; this is
        an equality, not just ``is an element of'') \ts{3}{1}{54:47}\ts{3}{1}{55:08}.
  \item Use the definition of $\oplus$ blindly on the two representatives that happened to be there, $a'$ and $b'$, and
        replace $a'=a-2m$, $b'=b-2n$:
        $a'+b'=(a-2m)+(b-2n)=a+b-2(m+n)$, by the associative and the commutative law
        \ts{3}{1}{55:08}\ts{3}{1}{55:28}\ts{3}{1}{55:49}.
  \item $a+b-2(m+n)$ and $a+b$ differ only by an even integer, so by definition they lie in the same class:
        $[a'+b']=[a+b]$ \ts{3}{1}{55:49}\ts{3}{1}{56:10}.
  \item Using the definition of $\oplus$ backwards, $[a+b]=[a]\oplus[b]$ \ts{3}{1}{56:10}\ts{3}{1}{56:31}.
\end{enumerate}
So the operation is well defined, for arbitrary other representatives \ts{3}{1}{56:31}.

\begin{remark}[When is the check needed?]\label{rem:cl-wd}
Care is needed only if the definition of an operation on a quotient set uses representatives. If one manages to write the
definition without using representatives, no care has to be taken: it is just a normal definition. If representatives are
used, one has to do this check \ts{3}{1}{56:51}. This happens, in various shapes and forms, throughout many constructions in
mathematics and throughout many constructions of this course \ts{3}{1}{57:20}.
\end{remark}

\section{Construction of the number systems}\label{sec:cl-numbers}

The final section of this chapter (which is Section~1.8 of the course) is the construction of the natural numbers, the
integers, the rational numbers and the real numbers, \emph{including the operations on them} (we already talked about
the sets) \ts{3}{1}{57:40}\ts{3}{1}{58:00}. If the axioms of set theory are any good, we must be able to construct these
important sets. What follows is an outline: one could write books on each of these topics; some more details will appear on
problem sheet two (problem sheet one was referred to above) \ts{3}{1}{58:00}\ts{3}{1}{58:21}.

The two lines to remember are $\mathbb Z=(\N\times\N)/{\sim}$ and $\Q=(\mathbb Z\times\mathbb Z^*)/{\sim}$: each new number
system is a quotient set of pairs of the previous one.

% ------------------------------------------------------------------
\subsection*{The natural numbers}

Recall that from the axiom of infinity (\cref{ax:se-infinity}, \cref{rem:se-naturals}) we got the set $\N$ whose elements are
the sets $0,1,2,3,\dots$, namely $0=\emptyset$, $1=\{\emptyset\}$, $2=\{\{\emptyset\}\}$, and so on \ts{3}{1}{58:43}\ts{3}{1}{59:03}\ts{3}{1}{59:24}.
Incidentally, the computer scientists' zero is exactly the zero of mathematics: wonderful \ts{3}{1}{59:24}. We now wish to
establish an addition on $\N$, in a set-theoretic way, derived from the axioms \ts{3}{1}{59:45}.

\begin{definition}[New concepts: successor map]\label{def:cl-succ}
The \textbf{successor map} $s\colon\N\to\N$ takes $n\in\N$ to the set with the element $n$: $s(n):=\{n\}$
\ts{3}{1}{59:45}\ts{3}{1}{1:00:11}\ts{3}{1}{1:00:33}.
\end{definition}
Example: the successor of $2$. The number $2$ is a short form of $\{\{\emptyset\}\}$; adding another layer of brackets
gives $\{\{\{\emptyset\}\}\}$, which is a short form of $3$. So $s(2)=3$ \ts{3}{1}{1:00:33}\ts{3}{1}{1:00:53}.

To make progress we also need a predecessor map.

\begin{definition}[New concepts: predecessor map]\label{def:cl-pred}
Let $\N^*:=\N\setminus\{0\}$ (the star means ``without the zero''; $\{0\}=\{\emptyset\}$; the complement was defined in
\cref{def:se-complement}) \ts{3}{1}{1:00:53}\ts{3}{1}{1:01:13}\ts{3}{1}{1:01:35}\ts{3}{1}{1:01:55}. The \textbf{predecessor map}
$p\colon\N^*\to\N$ assigns to $n$ the element $m\in n$ \ts{3}{1}{1:02:18}.
\end{definition}
How does this work? We need to go backwards, reducing a layer of brackets, and the trick is to take the element of the
set: $n$ has exactly one element. For instance $p(2)=p(\{\{\emptyset\}\})$; the set $2$ has only one element, namely
$\{\emptyset\}=1$, so $p(2)=1$ \ts{3}{1}{1:02:18}\ts{3}{1}{1:02:39}\ts{3}{1}{1:03:00}\ts{3}{1}{1:03:20}.

Now define the $n$-th power of the successor map \ts{3}{1}{1:03:20}\ts{3}{1}{1:03:42}. Recursively, with $s^0:=\mathrm{id}_\N$
(zero times take the successor: stay where you are), $s^1:=s$, and
\[
  s^n:=s\circ s^{p(n)}\qquad(n\in\N^*)
\]
\ts{3}{1}{1:03:42}\ts{3}{1}{1:04:03}\ts{3}{1}{1:04:23}\ts{3}{1}{1:04:44}.
\begin{coursenote}[Reconstruction of the recursion]
The blackboard line was written and changed twice (``hang on; it is easier to say informally\dots'' [?]). The recursion above is
the one consistent with all the later examples: $s^n$ is defined from $s^{p(n)}$, started at $s^0=\mathrm{id}$, and
Schuller later insisted that the start must be at $0$ so that $m+0$ makes sense \ts{3}{1}{1:07:20}\ts{3}{1}{1:08:02}.
\end{coursenote}

\begin{definition}[New concepts: addition on $\N$]\label{def:cl-addN}
The addition is the map $+\colon\N\times\N\to\N$,
\[
  (m,n)\mapsto m+n:=s^n(m),
\]
taking a pair in the Cartesian product to the object we want to call $m+n$: start with $m$ and $n$ times apply the
successor map \ts{3}{1}{1:04:44}\ts{3}{1}{1:05:07}\ts{3}{1}{1:05:28}.
\end{definition}
Everything is neatly defined. Examples:
\begin{itemize}
  \item $2+1=s^1(2)=s(2)=3$ (strictly, there is an intermediate step: $s^1(2)=s(s^0(2))=s(2)$, because the recursion must
        be run one step further back) \ts{3}{1}{1:05:28}\ts{3}{1}{1:05:51}\ts{3}{1}{1:08:02}\ts{3}{1}{1:08:22};
  \item $1+2=s^2(1)=s(s^1(1))=s(s(1))=s(2)=3$ \ts{3}{1}{1:05:51}\ts{3}{1}{1:06:11}\ts{3}{1}{1:06:33}.
\end{itemize}
``You say, ah, it must be the same; it looks very different in the beginning.'' This generalises \ts{3}{1}{1:06:33}: one gets the
commutative addition, and one can also show it is associative \ts{3}{1}{1:06:33}\ts{3}{1}{1:06:57}.

What about the neutral element? Zero, because $m+0=s^0(m)=m$, as $s^0$ is the identity: you do nothing
\ts{3}{1}{1:06:57}\ts{3}{1}{1:07:20}\ts{3}{1}{1:07:41}\ts{3}{1}{1:08:22}\ts{3}{1}{1:08:43}. (Schuller first stumbled here, ``not so
good, we should have started here, I'm sorry, this is live and in colour'', and then ran the recursion one step further
back.) And $0+m=m$ ``you figure it out'' \ts{3}{1}{1:08:43}.

What about the inverse element of the addition? It would be an element which, added to $m$, gives the neutral element. But
$5+(-5)=0$ needs a $-5$, and there is no such thing in $\N$. So $(\N,+)$ is not a group, not a commutative group: it lacks one
of the group axioms. That motivates the definition of the integers $\mathbb Z$ \ts{3}{1}{1:08:43}\ts{3}{1}{1:09:04}. The
increase in calculational power due to these musings is zero, that is clear; the point is to show how exactly this follows
from the axioms of set theory, and that indeed all these axioms need to be used to reconstruct even high-school mathematics.
That will be useful later \ts{3}{1}{1:09:24}\ts{3}{1}{1:09:45}.

% ------------------------------------------------------------------
\subsection*{The integers}

\begin{definition}[New concepts: the integers]\label{def:cl-Z}
The set $\mathbb Z$ is defined as the quotient set
\[
  \mathbb Z:=(\N\times\N)/{\sim},
\]
where the relation $\sim$ on the pairs of natural numbers is
\[
  (m,n)\sim(p,q)\ :\Longleftrightarrow\ m+q=p+n
\]
\ts{3}{1}{1:09:45}\ts{3}{1}{1:10:10}\ts{3}{1}{1:10:36}\ts{3}{1}{1:10:57}\ts{3}{1}{1:11:20}.
\end{definition}

First check that $\sim$ is an equivalence relation \ts{3}{1}{1:11:20}\ts{3}{1}{1:11:40}. Symmetry: if $(m,n)\sim(p,q)$, then to get
$(p,q)\sim(m,n)$ one swaps $m$ and $p$ and at the same time $n$ and $q$; this just swaps the sides of the equation, which is
still the same equation \ts{3}{1}{1:11:40}\ts{3}{1}{1:12:01}. Reflexivity: $(m,n)\sim(m,n)$ is $m+n=n+m$, also clear
\ts{3}{1}{1:12:01}\ts{3}{1}{1:12:21}. Transitivity can also be checked; ``let's not do this right now''
\ts{3}{1}{1:12:21}.

\begin{exercise}[Transitivity]\label{ex:cl-transitivity}
Check that $\sim$ on $\N\times\N$ is transitive: from $m+q=p+n$ and $p+t=r+q$ derive $m+t=r+n$ (only use the commutativity and
associativity of $+$ on $\N$, and that $a+c=b+c$ implies $a=b$) \ts{3}{1}{1:12:21}.
\end{exercise}

\begin{intuition}[Pairs as differences]\label{int:cl-diff}
The idea (not exact mathematics: ``it just goes in a little cloud'') is that the pair $(m,n)$ stands for what we naively
would call $m-n$ \ts{3}{1}{1:12:21}\ts{3}{1}{1:12:42}\ts{3}{1}{1:13:03}. With two natural numbers one can read off every integer
this way, but in many ways: $1-2$ is the same as $3-4$, and these are the same integer, which is precisely why we want to
identify them \ts{3}{1}{1:13:25}\ts{3}{1}{1:13:45}. When are two differences the same? $m-n=p-q$: take $q$ to the other side and
$n$ to the other side to get $m+q=p+n$ \ts{3}{1}{1:13:03}\ts{3}{1}{1:13:25}. One could have written $m-n=p-q$, but one cannot,
because one does not know what minus means yet: that is the problem of writing it down directly. After moving to the other
side only pluses are left, so the clever idea is to define everything using only the addition on $\N$
\ts{3}{1}{1:14:05}\ts{3}{1}{1:14:26}. One then reads off every integer in various ways, and puts on equivalence-relation glasses
that cannot distinguish these ways any more, and gets exactly the set $\mathbb Z$ \ts{3}{1}{1:14:26}\ts{3}{1}{1:14:46}.
\end{intuition}

Is this the $\mathbb Z$ we normally have? According to these musings, yes \ts{3}{1}{1:14:46}\ts{3}{1}{1:15:06}. But we also wish
to identify $\N$ with a part of $\mathbb Z$. Normally one thinks $\N\subseteq\mathbb Z$; it does not quite lie in this set
(it cannot, since $\mathbb Z$ is now a set of equivalence classes of pairs), so as written that cannot be true
\ts{3}{1}{1:15:06}\ts{3}{1}{1:15:28}. What is true is that one can \emph{embed} $\N$ into $\mathbb Z$: a natural number $n$ is
identified with the equivalence class $[(n,0)]$ \ts{3}{1}{1:15:28}\ts{3}{1}{1:15:48}\ts{3}{1}{1:16:09}, and in this sense it lies in
there. The inverse of a natural number is then defined as $-n:=[(0,n)]$ \ts{3}{1}{1:17:11}\ts{3}{1}{1:17:32}\ts{3}{1}{1:17:53}.
It is of course also an element of $\mathbb Z$.

A student asks whether one can then strictly say that $\N$ is a subset of $\mathbb Z$. No, strictly speaking not, because it
has a totally different structure; but you can make this embedding, redefine the elements of $\N$ as these
equivalence classes, and then they are a subset: that is the idea \ts{3}{1}{1:16:09}\ts{3}{1}{1:16:29}\ts{3}{1}{1:16:50}. Is there
anything more to say on $\N$ being a subset? No; because of the definition of the equivalence relation, the pairs that are
identified are all in the same class \ts{3}{1}{1:16:50}\ts{3}{1}{1:17:11}. A similar thing happens with fractions, which we
might look at in a second, otherwise it goes on the problem sheet \ts{3}{1}{1:17:11}.

What about the addition on $\mathbb Z$? ``Example: $2+(-1)$''; but the plus here must be the plus on $\mathbb Z$, which we have
not defined yet: we do not know what plus is, and we of course want to inherit it \ts{3}{1}{1:17:53}\ts{3}{1}{1:18:14}.

\begin{definition}[Addition on $\mathbb Z$]\label{def:cl-addZ}
$+_{\mathbb Z}\colon\mathbb Z\times\mathbb Z\to\mathbb Z$ is defined, using only the addition on $\N$ and representatives, by
\[
  [(m,n)]+_{\mathbb Z}[(p,q)]:=[(m+p,\ n+q)]
\]
\ts{3}{1}{1:18:14}\ts{3}{1}{1:18:34}\ts{3}{1}{1:18:55}\ts{3}{1}{1:19:17}.
\end{definition}
Being courageous, this is very likely right. It uses representatives, so it has to be checked that it is well defined
\ts{3}{1}{1:19:17}\ts{3}{1}{1:19:41}. The intuition is $(m-n)+(p-q)$: one adds up the positively contributing numbers, adds up the
negatively contributing ones, and their sum is subtracted. But the intuition is just the idea behind the definition; whether it
is a valid definition needs to be checked, and it is well defined \ts{3}{1}{1:19:41}\ts{3}{1}{1:20:01}.

\begin{example}[$2+(-3)$ in $\mathbb Z$]\label{ex:cl-2m3}
This takes place in $\mathbb Z$, and every element of $\mathbb Z$ of the form $[(n,0)]$ or $[(0,n)]$ is denoted by its integer
number \ts{3}{1}{1:20:01}\ts{3}{1}{1:20:22}. The $2$ in $\mathbb Z$ is $[(2,0)]$ (one could have written $[(3,1)]$ instead), the $-3$
is $[(0,3)]$ (the simple representative), and then
\[
  \begin{aligned}
  2+_{\mathbb Z}(-3)&=[(2,0)]+_{\mathbb Z}[(0,3)]=[(2+0,\ 0+3)]\\
  &=[(2,3)]=[(0,1)]=-1,
  \end{aligned}
\]
because $(2,3)\sim(0,1)$ by the definition of the equivalence relation ($2+1=0+3$) \ts{3}{1}{1:20:22}\ts{3}{1}{1:20:42}\ts{3}{1}{1:21:04}\ts{3}{1}{1:21:24}.
``Hallelujah, this is how this works.''
\end{example}
Obviously one could have defined a multiplication on $\mathbb Z$ in a similar fashion, inheriting it: ``more of the same''. The
point is the basic principle, everything from axiomatic set theory \ts{3}{1}{1:21:45}.

\begin{exercise}[Well-definedness on $\mathbb Z$]
Prove that $+_{\mathbb Z}$ is well defined. This is a long exercise: see \cref{ex:cl-wd-Z} in the appendix.
\end{exercise}

\subsection*{The rational numbers}

(``Any teachers among you? No teachers, what a shame.'' \ts{3}{1}{1:22:06}.) The rationals work similarly: first define them as
a set, then the operations \ts{3}{1}{1:22:06}\ts{3}{1}{1:22:27}.

\begin{definition}[New concepts: the rational numbers]\label{def:cl-Q}
Let $\mathbb Z^*:=\mathbb Z\setminus\{0\}$. The set $\Q$ is the quotient set
\[
  \Q:=(\mathbb Z\times\mathbb Z^*)/{\sim},
\]
where a pair $(x,y)$ of an integer and a non-zero integer is equivalent to a pair $(u,v)$ if
\[
  (x,y)\sim(u,v)\ :\Longleftrightarrow\ x\cdot v=u\cdot y
\]
\ts{3}{1}{1:22:27}\ts{3}{1}{1:22:49}\ts{3}{1}{1:23:09}\ts{3}{1}{1:23:30}\ts{3}{1}{1:23:51}\ts{3}{1}{1:24:12}.
\end{definition}
Here $\mathbb Z$ is already thought of as equipped with both an addition and a multiplication; one can believe that the
construction works in a similar fashion \ts{3}{1}{1:23:51}.

The idea: in elementary school we write a fraction $x/y$; the fraction bar morphs into a comma, and $x$ and $y$ stand on the left
and the right of it, numerator and denominator \ts{3}{1}{1:24:12}\ts{3}{1}{1:24:34}\ts{3}{1}{1:24:55}. But that is not quite true,
because the fraction $2/3$ is the same as $4/6$ (you can cancel common factors); so a fraction is not the pair but the
equivalence class of the pair \ts{3}{1}{1:24:55}\ts{3}{1}{1:25:16}. Example: $2/3=4/6$ because $2\cdot6=3\cdot4$; the rule
implements that extending or cancelling factors gives the same fraction. The glasses we put on now ignore common factors of
numerator and denominator \ts{3}{1}{1:25:16}\ts{3}{1}{1:25:37}\ts{3}{1}{1:25:58}. So fractions are indeed pairs of numbers, in
the numerator and in the non-zero denominator, but under the identification of cancellation: very simple
\ts{3}{1}{1:25:58}\ts{3}{1}{1:26:19}.

In fact the rational numbers have absolutely nothing to do with division. In school it is usually alluded to: ``what is $8$
divided by $2$? It is $4$'': this is $8/2$, and they pretend it is the same $4$ as the $4$ in $\mathbb Z$. That is not true,
because one has to identify it as a fraction: it is $[(8,2)]=[(4,1)]$, the fraction $4/1$; and one can embed the integers into the
rationals by representing an integer $x$ by $[(x,1)]$, by $x/1$ if you wish \ts{3}{1}{1:26:19}\ts{3}{1}{1:26:39}\ts{3}{1}{1:27:00}\ts{3}{1}{1:27:21}.
Whenever we manage to get a $1$ down there, we identify it with the integer: this is the embedding, much like with the minus
signs before \ts{3}{1}{1:27:21}\ts{3}{1}{1:27:42}.

\begin{definition}[Operations on $\Q$]\label{def:cl-opsQ}
With representatives, using only the structure on $\mathbb Z$ we already have \ts{3}{1}{1:27:42}\ts{3}{1}{1:29:26}:
\begin{itemize}
  \item addition: $[(x,y)]+_\Q[(u,v)]:=[(xv+yu,\ yv)]$ \ts{3}{1}{1:28:02}\ts{3}{1}{1:28:23}\ts{3}{1}{1:28:45};
  \item multiplication: $[(x,y)]\cdot_\Q[(u,v)]:=[(xu,\ yv)]$ \ts{3}{1}{1:29:06}.
\end{itemize}
\end{definition}
Addition is difficult: one first has to bring the fractions to the same denominator, which trivially can be achieved by
multiplying by the other denominator ($yv$ at the bottom), and then adds the numerators $xv+yu$; that is the rule given for the
addition of fractions \ts{3}{1}{1:28:02}\ts{3}{1}{1:28:23}\ts{3}{1}{1:28:45}. The rule for the multiplication of fractions is the
simple one. The plus in the numerator is the plus on $\mathbb Z$ and the products are in $\mathbb Z$, so one is always allowed to
use only structure that exists already \ts{3}{1}{1:29:06}\ts{3}{1}{1:29:26}. Both operations are well defined, as one may wish to
check.

\begin{remark}[The fool's addition]\label{rem:cl-fool}
Here comes the typical ill-defined addition, ``the fool's addition'' \ts{3}{1}{1:29:26}\ts{3}{1}{1:29:50}:
\[
  [(x,y)]\ \tilde+\ [(u,v)]:=[(x+u,\ y+v)],
\]
the sum of the numerators and the sum of the denominators \ts{3}{1}{1:29:50}\ts{3}{1}{1:30:12}. ``Of course that hurts.''
(A student asks, about this part of the lecture, how one can talk about the real numbers if one does not have them yet: a
slip of the tongue, ``of course we land there''; $\Q$ was meant \ts{3}{1}{1:30:12}\ts{3}{1}{1:30:35}.) One might delude oneself
into this definition, but it turns out to be ill defined: if one chooses different representatives for the same fractions, this
addition will generically yield a different fraction \ts{3}{1}{1:30:35}\ts{3}{1}{1:30:56}. This is the reason why we insist on
the complicated rule for the addition of fractions: not because it corresponds more to our intuition about cakes and dividing
cakes, but because the other is simply ill defined. ``There are always attempts to simplify the school curriculum, but this
will never come up: it is simply undefined'' \ts{3}{1}{1:30:56}\ts{3}{1}{1:31:16}\ts{3}{1}{1:31:38}.
\end{remark}
\begin{coursenote}[A concrete counterexample]
Not given in class: $[(1,2)]=[(2,4)]$, so the two sums $[(1,2)]\,\tilde+\,[(1,3)]=[(2,5)]$ and
$[(2,4)]\,\tilde+\,[(1,3)]=[(3,7)]$ should coincide; but $2\cdot7=14\ne15=3\cdot5$. This is
\cref{ex:cl-wd-Q} in the appendix.
\end{coursenote}

\subsection*{The real numbers}

Because time was up there is just one more remark on the reals \ts{3}{1}{1:31:38}. They can also be defined by way of a quotient
set: take the set $\mathcal A$ of \emph{almost homomorphisms} on $\mathbb Z$ (what that is will be learned on problem sheet two),
and a suitable equivalence relation; one can show that then nice objects like $\sqrt2$, which one of course cannot find in
$\Q$, actually lie in this set \ts{3}{1}{1:31:38}\ts{3}{1}{1:31:59}\ts{3}{1}{1:32:20}.
\begin{coursenote}[Almost homomorphisms: not said in class, [?] to be matched with problem sheet two]
The standard version (the Eudoxus reals): $f\colon\mathbb Z\to\mathbb Z$ is an almost homomorphism if
$\{f(m+n)-f(m)-f(n)\mid m,n\in\mathbb Z\}$ is finite (bounded); $f\sim g$ if $f-g$ is bounded; the quotient is
(a model of) $\R$. This is only stated to fix the idea.
\end{coursenote}

\begin{history}[Kronecker's dictum, and Dedekind cuts]
In class \ts{3}{1}{1:32:40}: ``maybe you know this dictum by Kronecker, that the integers were handed to us by God and all the
rest is man's work''; in our case the integers are handed to us by axiomatic set theory, and the rest is further work. There are
other ways to understand the reals, the Dedekind cuts, which are probably more standard; this construction is presented as
just one line of always taking quotient sets to define the new set of numbers that one needs \ts{3}{1}{1:33:00}\ts{3}{1}{1:33:21}.\par
\smallskip
\emph{Checked.} The dictum, ``Die ganzen Zahlen hat der liebe Gott gemacht, alles andere ist Menschenwerk'', is attributed to
L.~Kronecker (from a 1886 talk) and was reported by H.~Weber in his obituary of Kronecker (\emph{Jahresber.\ Deutsch.\ Math.-Verein.}\ 2, 1893).
Dedekind cuts: R.~Dedekind, \emph{Stetigkeit und irrationale Zahlen} (1872).
\end{history}

So we have arrived, as Schuller puts it, in some class of high school (``10th class'') with the construction of the real
numbers, all from axiomatic set theory \ts{3}{1}{1:33:21}.

\paragraph{Outlook.} Next time: topology. We go back to ordinary sets, select certain subsets of a set $M$ and christen them
\emph{open sets}, whatever that means; there will be axioms for what kind of collection of subsets of $M$ one may call open
sets. Such a collection, largely not unique, is called a \emph{topology} on the set; it is the weakest known structure that
can be put on a set in order to define notions of continuity and notions of convergence \ts{3}{1}{1:33:42}\ts{3}{1}{1:34:02}\ts{3}{1}{1:34:22}.

\section*{Key concepts}
\begin{keyconcepts}
\textbf{Retrieval questions.}
\begin{enumerate}
  \item What is a map in terms of relations, and why is the notation $\varphi(a)$ an abuse of notation?
  \item Define injective, surjective, bijective; define $A\cong_{\mathrm{set}}B$. Why is there generically no unique bijection?
  \item When is a set infinite, countably infinite, finite? Give an example with $\mathbb Z$ and $\N$.
  \item What do you need in order to speak of an inverse map? Define the pre-image of a subset of the target.
  \item State the three axioms of an equivalence relation; which of ``same opinion'', ``sibling of'', ``taller than'', ``in love with''
        satisfy them?
  \item State the two key properties of equivalence classes. Why is $M/{\sim}$ a set?
  \item When must one check that a map out of a quotient set is well defined? Check it for $[a]\oplus[b]:=[a+b]$ on $\mathbb Z/{\sim}$
        with $m\sim n:\Leftrightarrow m-n\in2\mathbb Z$.
  \item Define $s$, $p$ and the addition on $\N$; compute $1+2$. How are $\mathbb Z$ and $\Q$ obtained as quotient sets? Why is
        $[(x,y)]\,\tilde+\,[(u,v)]:=[(x+u,y+v)]$ not a valid definition?
\end{enumerate}
\textbf{Concepts.}
\begin{itemize}
  \item Classification of spaces by structure-preserving maps (\cref{int:cl-theme}); map as a relation, image
        (\cref{def:cl-map,def:cl-image}); injective, surjective, bijective (\cref{def:cl-bij}).
  \item Set-theoretic isomorphism $A\cong_{\mathrm{set}}B$; infinite, countable, finite (\cref{def:cl-iso,def:cl-infinite}).
  \item Composition $\psi\circ\varphi$, associativity, identity, inverse of a bijection, pre-image
        (\cref{def:cl-comp,def:cl-inverse,def:cl-preimage}).
  \item Equivalence relation: reflexive, symmetric, transitive; class $[m]$; the two key properties; quotient set
        $M/{\sim}$ and complete system of representatives (\cref{def:cl-equiv,def:cl-class,prop:cl-classes,def:cl-quotient,rem:cl-representatives}).
  \item Well-definedness of maps defined through representatives (\cref{rem:cl-wd}).
  \item $s(n)=\{n\}$, $p$, $m+n=s^n(m)$ (\cref{def:cl-succ,def:cl-pred,def:cl-addN}); $\mathbb Z=(\N\times\N)/{\sim}$ with
        $m+q=p+n$, $\Q=(\mathbb Z\times\mathbb Z^*)/{\sim}$ with $xv=uy$ (\cref{def:cl-Z,def:cl-Q}); the fool's addition
        (\cref{rem:cl-fool}).
\end{itemize}
\end{keyconcepts}
